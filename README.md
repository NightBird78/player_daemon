# Advanced WebSocket Player Daemon

**Сучасний дистанційний аудіоплеєр** для Linux (і Windows) з підтримкою YouTube та локальних файлів.

Керуйте музикою зі свого комп’ютера з будь-якого пристрою - телефону, планшета, іншого ПК чи навіть браузера на холодильнику - через зручний веб-інтерфейс.

## Основна ідея

Хотілося просто «замовити» пісню своєму комп’ютеру з дивана, не встаючи.  

**Adv WS Player** - це легкий, швидкий і надійний daemon, який дозволяє додавати треки в чергу та керувати відтворенням у реальному часі через WebSocket.

---

## Ключові можливості

- **Дві черги з пріоритетами**:
  - **Active Queue** - треки, які треба слухати зараз
  - **Passive Queue** - фонова музика (вмикається автоматично після закінчення Active)
- Підтримка **YouTube** (посилання та плейлисти) через `yt-dlp`
- Підтримка **локальних MP3-файлів** з читанням ID3-тегів
- **WebSocket** - керування в реальному часі
- **MPRIS** (Linux) та **SMTC** (Windows) - інтеграція з системними медіа-клавішами, KDE Connect, GNOME тощо
- Зручний веб-інтерфейс з прогрес-баром і логами
- Автоматичний перехід з Active Queue → Passive Queue

---

## Технологічний стек

- **Backend**: Python 3 + asyncio + websockets
- **Плеєр**: [mpv](https://mpv.io/) (через Unix socket / IPC)
- **YouTube**: [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- **Метадані**: `mutagen`
- **MPRIS (Linux)**: `pydbus` + GLib
- **Frontend**: Чистий HTML + CSS + JavaScript (односторінковий)

## Вимоги та встановлення

### Linux

```bash
sudo apt update
sudo apt install mpv python3-pip python3-dbus python3-gi gir1.2-glib-2.0

pip install websockets pydbus mutagen gbulb yt-dlp aiohttp pygobject==3.48.2
```

### Windows

```bash
pip install websockets mutagen yt-dlp aiohttp winsdk
```

Також встановіть [mpv](https://mpv.io/) (з офіційного сайту або Microsoft Store).

> **Рекомендація**: використовуйте віртуальне середовище (`venv`).

### Оновлення yt-dlp

```bash
pip install -U yt-dlp
```

## Запуск

1. Клонуйте репозиторій
2. Запустіть сервер:

```bash
python main.py
```

Сервер запускається на `http://localhost:8765`

3. Відкрийте цю адресу в браузері на будь-якому пристрої в одній мережі.

### Автозапуск (Linux)

Створіть systemd user unit:
`~/.config/systemd/user/adv-ws-player.service`

## Як користуватися

### Додавання треків

- **Play** - вставте посилання YouTube або шлях до `.mp3` файлу
- **Playlist** - вставте посилання на YouTube-плейлист (додасться в Passive Queue)

### Керування

- Кнопки в веб-інтерфейсі: Play/Pause, Next, Stop
- Системні медіа-клавіші та програми (KDE Connect, polybar, media keys тощо)

### Логи

- **Actions Log** - команди, що приходять від інших клієнтів
- **Response Log** - відповіді сервера та зміни стану

Логи допомагають розуміти, що відбувається, особливо при роботі з кількома пристроями/клієнтами.

## Архітектура

- `Active Queue` має вищий пріоритет
- Після закінчення всіх треків в Active Queue автоматично починається відтворення з Passive Queue
- Асинхронна архітектура на asyncio
- Чітке розділення логіки черг, плеєра та веб-інтерфейсу
